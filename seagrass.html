Seagrass taxa (AphiaIDs found in occurrence.txt)

Selection set: every occurrence.txt row whose scientificName names a seagrass taxon contributed its scientificNameID AphiaID. Events are selected exclusively through these AphiaIDs. Rows with a blank scientificNameID were matched back to their taxon's AphiaID (resolved from data, or via WoRMS when missing there). Halophila sp. rows without an ID remain excluded (open-nomenclature, unresolvable) and are flagged below.

Notes

  • Selection: an event is seagrass iff at least one of its occurrences carries a seagrass AphiaID (from the registry table above) in scientificNameID, or a blank ID with a name that maps to a registry AphiaID. All AphiaIDs in the registry were observed in the occurrence.txt files themselves.
  • Unresolved: Halophila sp. rows with a blank ID (open-nomenclature; WoRMS returns 404) are excluded and flagged in the registry (see overview_aphiaids.json).
  • Unlike a habitat-based filter this is taxon-exact: e.g. dataset 4018 (Miami-Dade benthic monitoring) becomes seagrass-bearing because its Braun-Blanquet transects record Halodule wrightii etc., while pure water-quality events stay excluded.
  • Because seagrass coverage is inferred from occurrences, datasets that are polygon habitat maps (3014, 3019, 4045, 566, 71) have no occurrence rows and therefore don't contribute here — unlike on the all-records page.
  • Aggregation: pre-computed with Python (h3 4.5, pandas); no individual records ship with this page.
  • This page loads Leaflet, h3-js and ECharts from public CDNs — an internet connection is required for the first load.
